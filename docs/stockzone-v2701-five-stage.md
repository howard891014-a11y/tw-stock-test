# StockZone v2.7.0.1 — 五階段位置（新版顯示）

## 完成
- 將唯一的「五階段位置」主題卡從「分析」移到「總覽」共振分析卡上方。
- 五階段單一主要波段尺度：60–120 日價格結構，5–20 日確認細分狀態；使用 ATR 協助校正支撐判讀。
- 固定五階段、14 種狀態：築底（尚未止跌／止跌）、轉強（初步轉強／突破確認／回測守穩）、爬坡（正常上漲／短期過熱／健康回檔）、加速（加速啟動／強勢延續／動能降溫）、高檔（高檔震盪／轉弱警戒／轉弱確認）。
- 不引入中性盤整或額外模式；長期箱型仍根據近期主要波段位置歸類。
- 不以 RSI/乖離率的過熱，單獨推定進入第五階段。
- 為保留原版玩法、風險及共振模型結果，原版計算函式完整保留為 `calculateLegacyStageForExistingScoring`，**新版五階段只作總覽顯示**；交易引擎仍使用未修改的舊版 stage 輸入。
- 套件、側欄、前端 app 快取版本統一更新至 v2.7.0.1。

## 測試與限制
- `npm run validate:five-stage`：合成 OHLCV 檢查各階段、關鍵狀態、UI 唯一定位及舊邏輯 SHA256 一致性。
- `npm run validate:app-version`：版本一致性。
- `node scripts/validate-project-layout.js`：專案布局。
- 本版尚未使用完整真實歷史行情回測分類準確性，合成案例通過不代表實際績效經驗證。
- 原有部分舊版驗證腳本硬編碼 v2.6.x 版本；不可將其視為新版整體通過。
