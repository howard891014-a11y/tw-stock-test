# StockZone v2.7.0.45｜五年 R1 取樣規則

## 定案

- 五年資料最多保留最近 **20** 筆完整 60 交易日觀察樣本；不是保證每檔都有 20 筆。
- **正式合格最低筆數維持 10 筆**。勝率 ≥50%、平均淨報酬 >0、中位數 >0 的既有條件不變。
- 1～9 筆且有可用績效：玩法（參考）；0 筆：資料不足，不能推斷玩法。
- 完整 60 日視窗內遇到無法直接計入一般漲跌的 OHLC 異常或相鄰收盤價跳變 >35%：捨棄整筆，從異常日的**下一個有效交易日**開始重新取 60 日。完整視窗中的所有策略同進同出地使用相同觀察起點。
- 對異常原始 OHLC，資料清理已排除該根；重新起算點是清理後的**第一根有效 K**，不再多跳過一天。無法確定異常日期時保持拒算。
- 進場判斷需要的前 120 根日 K 僅影響 MA120 歷史訊號／策略比較，不再阻止五種玩法的純價格績效回測。缺 MA120 時不填補或虛構進場訊號。
- 有異常而排除部分區間：既有 `partial` 訊號與參考標示維持。
- 5/15/20/40/60 日原交易模擬、停利停損、成本、OHLC 清洗及 35% 跳價檢查均不改；Neon、Yahoo 原始日 K、W3、XY、共振均不改。
- 歷史觸及率與 R1 共用這套有效觀察樣本。

## 邊界例子

若第二段從索引 60 開始，索引 105（該段第45日）是跳變異常：整段捨棄；從索引 106（異常隔日）重新起算新的完整 60 日窗口。

## 驗證

`npm run validate:release45` 包含樣本 9/10/20 邊界、跨異常不接合、異常隔日重啟、不可定位異常拒算、歷史觸及率同步、原 R1 公式雜湊與部署／授權的既有驗證。正式 Vercel 實機驗證尚未進行。
