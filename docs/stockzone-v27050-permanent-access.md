# StockZone v2.7.0.50 — 家人長期裝置授權

## 目標

- 既有管理員、家人已啟用裝置不設固定的 Neon 授權到期日，除非管理員撤銷。
- 新發出的邀請連結仍為**一次性**，預設 48 小時內啟用，避免連結長期外流。
- 已啟用裝置沿用同一安全 HttpOnly Cookie，普通使用時延長瀏覽器 Cookie 有效期；不建立第二套登入。
- 只改存取授權系統，不改 Neon 股票資料、W3／XY／R1 計算、23 個排程或 Vercel 網域。

## 正式部署步驟

1. 若尚未執行，於正式 Neon 執行 `docs/stockzone-v27050-permanent-access.sql`，新增 `permanent` 欄位並標記原有有效、未撤銷的裝置。此變更不影響舊版 .49 判斷，適合在部署前進行。
2. 以 `.49 → .50 CHANGE ONLY` 覆蓋 GitHub 原路徑並部署 Production。
3. 同一台手機開啟固定 Production 網址，確認原管理員與家人的授權仍有效；授權管理頁「裝置授權」顯示「長期有效（可隨時撤銷）」。
4. 用已授權及未授權瀏覽器測試；確認陌生人不可讀資料、授權有效、撤銷後無法存取；觀察 Vercel 排程正常。

## 真正的限制

「長期有效」是 Neon 授權沒有固定到期日，不是保證瀏覽器永遠保管身分憑證。為了安全，Cookie 每次正常造訪會更新其有限有效期（目前 365 日）。如果超過該期限完全沒有造訪、清除 Cookie、換手機或瀏覽器移除站台資料，就需要管理員重新發一條邀請連結。撤銷授權始終優先。

## 回滾

這次僅為原授權資料表新增欄位，不刪除欄位或紀錄。如果回滾到 .49，原 `expires_at` 仍會被舊版使用；新版本的「長期有效」保障只有在 .50 或相容的更新版生效。
