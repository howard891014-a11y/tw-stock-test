# StockZone v2.7.0.49 — 設定頁授權管理入口

- 從 v2.7.0.48 升級；不變更 Neon、正式網址、密鑰、Cron、W3、XY、R1 或共振。
- 在「設定」最上方加入一項「授權管理」；只有從 `/api/access?action=status` 確認 `authorized === true && role === 'admin'` 才會顯示。
- 每次打開設定重新查詢，禁用瀏覽器快取；任何 API／網路錯誤一律隱藏。避免權限被撤銷後仍使用先前顯示狀態。
- 點擊可使用現有 `/access-admin.html` 管理介面，不更換任何權限、授權或密鑰機制。
- 未授權、一般使用者即使自行輸入該網址，也無法取得管理員權限，後端 `/api/access` 保留獨立驗證與 403 拒絕。
- 往後可照常部署 CHANGE ONLY，既有 Neon 授權及 Cookie 不會因程式版號更新自動失效。

## 部署方式

將 CHANGE ONLY ZIP 檔案按照原目錄覆蓋現有 v2.7.0.48；不需修改 Vercel 環境變數、Neon 或重新產生授權連結。

部署後以同一個已啟用管理員權限的瀏覽器開啟 StockZone → 設定 → 授權管理。使用一般授權裝置測試時不應顯示該入口。
