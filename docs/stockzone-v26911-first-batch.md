# StockZone v2.6.9.11｜個股分析第一批實作

**來源基線**：v2.6.9.10 持股交易計畫完整程式；版本號遞增至 v2.6.9.11。

## 已完成

1. **維持原版共振 A**：短波、波段、券商、估值、壓力五家族來源及連續高斯權重、排序計算未重寫；沒有加入統計 B。最高排名峰值仍為「主要共振（預估高點）」。
2. **次要共振只許延伸**：從其餘獨立共振峰挑選高於主要價位、最靠前排名的候選；不再把價格較低的第二名稱為延伸。不符合就回傳 null，畫面顯示「暫無延伸目標」，不生成假的預測數字。
3. **取消第三個正式高點**：不再輸出樂觀共振目標，預期成長目標卡只有主要、次要兩個。總覽圖不再用估值價格填補缺失的延伸峰。
4. **近期技術操作獨立判讀**：新增「近期玩法｜進出場時機」模組，輸出近期適合模式、是否試單、試單比例、試單時機、補倉時機、停損條件。參考 MA5/10/20/60、近5/20日漲跌幅、20日實現波動率、布林、MACD、RSI/KD、量價、法人、融資、既有波段支撐以及 SR8.2（S1/S2/R1/R2）。資料不足及過期籌碼不冒充有效訊號。
5. **接上原買賣決策畫面**：顯示近期技術是否適合試單；若近期判讀為 0%，原有試單價仍作價位參考但明示現在不建議試單，避免一邊說等待、一邊說直接進場。**未覆寫既有風險、買賣價格、V4 玩法或下單功能。**
6. **建立交易計畫快照加存近期判讀**：保留原玩法、原始主次價與當時近期技術提示，與既有 localStorage 計畫相容；既有交易計畫生命週期維持原樣。

## 未完成／不宣稱完成

- **尚未正式回測試單 0／10／20% 的優劣**；這是明示的暫定保守試算比例，指計畫單筆部位的比例，並非總資產比例，不提供自動下單。
- 尚未改造已持股的固定玩法條件下動態重算邏輯、核心／機動倉正式調整、交易記帳與結算：這些是第二／三批。
- 仍未取得原共振 A 的完整歷史快照；**不宣稱共振預測成功率提高**。
- 未寫入 Neon/Supabase、未改 W3、未部署 Vercel；須使用者將本版檔案上傳部署。

- `npm run validate:batch1`：主次峰順位、無可用次峰、不生成樂觀高點、六項近期資訊、資料不足與不追價等情境均通過。
- `npm run validate:holding-plans`、`npm run validate:app-version`、`npm run validate:browser-storage`、`npm run validate:layout` 通過。
- 離線 Chromium (Playwright) 介面測試：實際載入原前端腳本、近期六欄填值、沒有第三目標 DOM、0 頁面錯誤。使用合成行情，不是即時行情或後測績效。

## 部署

若 GitHub 上已經部署 v2.6.9.10，可以覆蓋 **更新包** 的內容；如果尚未部署 v2.6.9.10，請以 **完整程式包** 作為同一基線後再部署。不要只複製 app.js 而漏掉新 `lib/recent-play-advice.js`；該模組由 index.html 在 app.js 前載入。
