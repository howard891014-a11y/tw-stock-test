# v2.7.0.44 — 五年 R1 異常日重取樣（資料零覆寫）

## 原則

- 仍使用 Yahoo 五年原始 OHLC，Neon 與 IndexedDB 格式不更動。
- 保留 120 日進場前資料、60 日取樣間距、五種 5/15/20/40/60 日持有策略與同一份 R1 `simulateTrade` 數學函式。
- 遇 >35% 相鄰收盤跳變或可定位日期的異常 OHLC，認定為價格基準斷層。**任何樣本不得跨越斷層**，不能刪掉一天後把前後價格拼接。
- 自動尋找下一個具有 120 個同價格基準歷史日 K 且未來 60 個日 K 同基準的進場點。下一次仍按 60 個交易日間隔取樣；已跳過窗口不補虛構結果。
- 無法定位日期的壞資料、資料少於 150 根、或排除後沒有完整樣本，維持拒絕回測。
- 五年 R1 與「歷史價格觸及率」統一採用相同有效樣本日期。觸及率的計算公式不變，異常窗口排除後標示參考。
- 因異常被跳過窗口，回測績效會顯示事件數量與日子，**只標示「參考」**；原本的動態倉位比例和持股計畫邏輯不變。
- 這不是除息權益校正，也不是完整五年含息報酬；排除異常期會造成選樣偏差，需要明確保留這個限制。

## 不變
- `cleanBars`、`entryCandidate`、`contextAt`、`simulateTrade`、`summarise` 原始內容逐位元組不變。
- W3、XY、Neon、共振、持股策略、授權與排程不變。

## 部署
- 若現有 GitHub 檔案是 `.43`，使用 `.43 → .44 CHANGE ONLY` 覆蓋原目錄；其他版本使用符合基準的差異包。
- 不需要更新 XY 或改動 Neon。Vercel 正式瀏覽器驗證尚未完成。
